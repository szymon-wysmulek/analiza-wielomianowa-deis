# analiza-wielomianowa-deis
Interaktywna analiza wielomianowa spektrogramów DEIS oraz symulacja układów elektrochemicznych. Materiał uzupełniający rozprawę doktorską.

## Uruchom aplikację

[Otwórz DEIS Polynomial Lab](https://szymon-wysmulek.github.io/analiza-wielomianowa-deis/)

Aplikacja działa bezpośrednio w przeglądarce, bez instalacji.
Zawiera trzy przykładowe zestawy eksperymentalne — powłokę akrylową, korozję wżerową i inhibitor korozji — oraz symulator obwodów zastępczych.
